# Keep `omx` as the primary operator-facing surface unless there is an explicit de

Keep `omx` as the primary operator-facing surface unless there is an explicit decision to break compatibility. Treat the Buu layer as a capability expansion on top of OMX: quarantine, provenance, cocoons, and selective fused forms should strengthen the existing runtime rather than force an early command-surface rename. Operationally, differentiate through real features first and only rebrand the CLI if the human explicitly wants a compatibility break.
