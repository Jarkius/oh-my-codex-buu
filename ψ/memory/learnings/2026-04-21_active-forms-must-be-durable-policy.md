# Active Forms Must Become Durable Policy

If absorption forms only affect overlay text, they are still decorative architecture. To matter operationally, an active form must:

- persist as explicit runtime state
- derive wake directives from active capabilities
- write those directives into durable project memory
- influence execution posture (`ralph`, `team`, verification planning)
- support export/import across repos

The useful boundary is:
- `source` = canonical repo state
- `seed` = distributable design + capability seed
- `reloaded` = awakened state with active form, directives, and policy snapshot

Keep `omx` as the operator surface. Put the power in the activated form, not in renaming the CLI.
